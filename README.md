## 📖 About This Repository

This repository is dedicated to mastering **Data Structures and Algorithms (DSA)** through practical implementations, problem-solving techniques, and optimized solutions using Java and Kotlin.

The primary goal is to strengthen computer science fundamentals, improve logical thinking, and prepare for technical interviews.

---

## 🎯 Objectives

- Build strong fundamentals in Data Structures and Algorithms.
- Improve logical thinking and problem-solving skills.
- Understand time and space complexity.
- Explore brute-force and optimized approaches.
- Write clean, readable, and maintainable code.
- Prepare for technical coding interviews.
- Maintain consistency in continuous learning.

## ⏱️ Time Complexity Cheat Sheet

| Complexity | Name | Example |
|:---:|:---|:---|
| O(1) | Constant | Array Index Access |
| O(log n) | Logarithmic | Binary Search |
| O(n) | Linear | Linear Search |
| O(n log n) | Linearithmic | Merge Sort |
| O(n²) | Quadratic | Bubble Sort |
| O(2ⁿ) | Exponential | Recursive Subset Generation |
| O(n!) | Factorial | Permutations |

### Data Structure Complexity

| Data Structure | Access | Search | Insertion | Deletion |
|:---|:---:|:---:|:---:|:---:|
| Array | O(1) | O(n) | O(n) | O(n) |
| Singly Linked List | O(n) | O(n) | O(1)* | O(1)* |
| Doubly Linked List | O(n) | O(n) | O(1)* | O(1)* |
| Stack | O(n) | O(n) | O(1) | O(1) |
| Queue | O(n) | O(n) | O(1) | O(1) |
| HashMap | — | O(1)** | O(1)** | O(1)** |
| Balanced BST | O(log n) | O(log n) | O(log n) | O(log n) |

> \* When the required node or predecessor is already known.
>
> \*\* Average-case complexity.
